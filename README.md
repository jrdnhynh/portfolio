# Jordan Huynh — Portfolio

My personal portfolio, designed as a nod to the Flash-era websites and early-2000s broadcast graphics I grew up on: flat pastel color, rounded "swoosh" menus, pixel-font labels and a ticking timecode.

**Live site:** [jordanhuynh.com](https://jordanhuynh.com)

## What's inside

- **Six sections:** Profile, Work, Career, Skills, School and Contact. Each one repaints the whole stage in its own color.
- **Trading cards:** every project, job and degree gets its own card in the style of old collectible cards, with generated artwork and the company or school logo.
- **Keyboard first:** arrow keys move between sections and items, 1–6 jump straight to a section, and M toggles sound effects. Mouse and touch work too.
- **JH-FM radio:** a little radio in the top bar that plays a synth loop generated live in the browser with the Web Audio API.
- **Recruiter mode:** one switch turns the whole site into a plain one-page resume.
- **An easter egg:** there's a hint in the footer.

## Built with

- HTML, CSS and vanilla JavaScript, with no framework and no build step
- [GSAP](https://gsap.com) for animation
- Web Audio API for sound effects and the radio
- Self-hosted fonts: M PLUS Rounded 1c, Dela Gothic One and Silkscreen
- Hosted on Vercel

## Accessibility

The site works fully with a keyboard, has visible focus states, and respects your system's reduced motion setting. Recruiter mode offers a plain, text-first version of everything.
